## 1. Установка и запуск

### 1.1. Требования

- **Python** 3.10+
- **PyAgentProlog** (пакет `prolog`) в `sys.path` — движок запросов.
- **PyVis** ≥ 0.3 — для интерактивной визуализации.
- **Gradio** 4.x / 5.x / 6.x.
- **tkinter** — для нативных диалогов выбора файлов.

### 1.2. Установка зависимостей

```bash
# Базовые зависимости
pip install gradio pyvis

# Опционально: для работы NL-импорта (русский/английский)
pip install pymorphy3 sentence-transformers natasha
# Для английского spaCy:
python -m spacy download en_core_web_sm
# Для русского spaCy (NER):
python -m spacy download ru_core_news_sm

# Опционально: для загрузки файлов (PDF, DOCX)
pip install PyPDF2 python-docx

# PyAgentProlog (если ещё не установлен)
pip install -e /путь/к/pyagentprolog
```

### 1.3. Запуск

```bash
kg-editor
```

Откроется браузер на `http://127.0.0.1:7860`.

**Дополнительные параметры CLI:**
```bash
kg-editor --host 0.0.0.0 --port 8080   # Доступ с других машин
kg-editor --share                      # Публичная ссылка gradio.live
kg-editor --no-browser                 # Не открывать браузер
```

Или через Python API:
```python
from kg_editor import launch
launch(host="0.0.0.0", port=8080)
```

## 3. Работа с проектом (Колонка 1)

### 3.1. 📂 Открыть
Загружает существующий `.pl` файл из файловой системы. Содержимое загружается в редактор, таблицы и визуализация обновляются.

### 3.2. 🆕 Создать
Создаёт новый проект в выбранной папке (создаётся файл `graph.pl` с шаблоном).

### 3.3. 💾 Сохранить
Сохраняет текущий граф в `.pl`-файл. Если файл уже открыт — перезаписывает его; иначе открывает диалог «Сохранить как».

### 3.4. 📚 Демо-граф
Загружает демонстрационный граф (`apple`, `iphone`, `spacex`, `elon_musk`) для быстрого ознакомления.

### 3.5. Статистика
Отображает текущее количество узлов, рёбер и атрибутов. Обновляется автоматически.

### 3.6. 📝 Импорт из естественного языка (NL)

Этот блок позволяет извлекать факты и запросы из текста. Блок поддерживает три сценария:

1. **Ручной ввод:**
   Введите краткий текст в поле «Краткий текст» (например: *«Илон Маск владеет SpaceX. Кто владеет SpaceX?»*) и нажмите **✨ Извлечь факты и запросы**.

2. **Загрузка из файла:**
   - Перетащите файл формата `.txt`, `.pdf`, `.docx` или `.fb2` в зону загрузки.
   - Приложение извлечёт из него текст и покажет статус: *«✅ Файл загружен (N символов)»*.
   - Появится кнопка **📝 Открыть текст в редакторе**.
   - Нажмите её, чтобы открыть **модальное окно** (на весь экран) с большим полем для просмотра и редактирования полного текста.
   - После редактирования нажмите **✅ Применить** (текст сохранится в памяти) или **❌ Отмена**.
   - Нажмите **✨ Извлечь факты и запросы** для обработки.

3. **Пользовательский конвертер (⚙️):**
   Если вы хотите использовать свой алгоритм извлечения (не встроенный `text_to_prolog.py`), раскройте аккордеон **«⚙️ Пользовательский конвертер»**:
   - Нажмите **📂 Выбрать .py** и укажите путь к вашему модулю.
   - Нажмите **✅ Загрузить**. Модуль должен содержать класс `TextToProlog` с методом `parse(text)` (возвращает кортеж `(факты, запросы)`) или `convert(text, mode="graph")`.
   - Чтобы вернуться к встроенному конвертеру, нажмите **↺ Встроенный**.

**Как это работает:**
- Система анализирует текст. Утверждения превращаются в факты и **добавляются** в текущий граф.
- Если в тексте найден вопрос (например, *«Кто владеет SpaceX?»*), он автоматически подставляется в поле «🔎 Запросы» (Колонка 3).
- Извлечённые сущности автоматически типизируются (PER → `person`, ORG → `org`, LOC → `place` и т.д. — см. палитру типов).

### 3.7. 📥 Импорт из Prolog
Вставьте Prolog-факты и нажмите **📥 Разобрать**. Текущий граф **заменяется** содержимым из текста.

### 3.8. 🔬 Диагностика
Показывает JSON с текущим состоянием (количество узлов, доступность PyAgentProlog, статус встроенного/пользовательского конвертера, список типов и предикатов).

## 4. Редактор графа (Колонка 2)

### 4.1. Вкладка «Узлы»
- Таблица **id / type / degree**.
- **Добавить:** введите `id` и `type` → **➕**.
- **Удалить:** выберите из списка → **🗑️** (удаляет узел и все его связи).

**Палитра типов:**
| Тип | Цвет |
|---|---|
| `concept` | 🔵 голубой |
| `person` | 🟢 зелёный |
| `org` / `organization` | 🟠 оранжевый |
| `place` / `loc` | 🟣 фиолетовый |
| `event` | 🔴 красный |
| `thing` | 💠 светло-голубой |
| `product` | 🟡 жёлто-оранжевый |

### 4.2. Вкладка «Рёбра»
- Таблица **idx / source / predicate / target**.
- **Добавить:** введите `source`, `target`, `predicate` → **➕**.
- **Удалить:** выберите из списка → **🗑️**.

### 4.3. Вкладка «Атрибуты»
- Таблица **idx / entity / name / value**.
- **Добавить:** введите `entity`, `name`, `value` → **➕**.
- **Удалить:** выберите из списка → **🗑️**.

### 4.4. Вкладка «Prolog source»
- **Сверху** — цветной просмотр с подсветкой синтаксиса.
- **Ниже (в аккордеоне)** — поле для ручного редактирования.
- **🔄 Обновить из графа** — пересобрать текст из модели.
- **📥 Применить из Prolog** — заменить граф текстом из поля.

## 5. Визуализация (Колонка 3, верх)

Интерактивный PyVis-граф с тёмной темой.

- **Узлы** — размер зависит от степени (количества связей).
- **Рёбра** — имеют увеличенную толщину и контрастный цвет (светло-серый `#8b949e`), чтобы оставаться видимыми даже при сильном отдалении.
- **Hover** — всплывающие подсказки для узлов и рёбер.

**Управление:**

| Действие | Результат |
|---|---|
| Колесо мыши | Зум вокруг курсора |
| Drag фона | Панорама |
| Drag узла | Перетаскивание (физика пересчитает) |
| Кнопки `+` / `−` / `⟳` | Зум / сброс вида |
| **Кнопка `⛶` (слева сверху)** | **Развернуть граф на весь экран** |
| Кнопка `✕` (в полноэкранном режиме) | Свернуть обратно |
| `Esc` (клавиша) | Выйти из полноэкранного режима |

## 6. Запросы (Колонка 3, низ)

Движок — **PyAgentProlog**. Запросы выполняются на «свежем» агенте, поэтому мутации (`assertz`, `retract`) не влияют на базовую модель.

### 6.1. Синтаксис
Введите запрос (точку можно не ставить) → **▶ Запрос**.

### 6.2. Доступные предикаты
Автоматически добавляются удобные правила:
```prolog
node(Id, Type) :- node(Id, _, Type).
edge(S, T) :- edge(S, T, _).
```
Поэтому работают: `node/2`, `node/3`, `edge/2`, `edge/3`, `attribute/3`, `\+`, `=`, `\=`, `is`, `findall/3`, `member/2`, `append/3` и другие стандартные предикаты.

### 6.3. Примеры запросов
- `node(apple, T).` — тип узла apple.
- `edge(X, Y, owns).` — кто чем владеет.
- `edge(A, B, _), \+ (A = B).` — все рёбра без петель.
- `findall(X, edge(apple, X, _), L).` — все цели рёбер apple.
- `node(A, person), node(B, org), edge(A, B, owns).` — персона, владеющая организацией.

### 6.4. Результат
JSON с решениями (например, `[{"X": "elon_musk", "Y": "spacex"}]`) или `{"result": true}` для ground-запросов. Лимит — 1000 решений.

## 7. Формат файла на диске

```prolog
node(apple, [], org).
node(spacex, [], org).
edge(apple, iphone, releases).
edge(elon_musk, spacex, owns).
attribute(iphone, release_year, '2022').
```

- **Идентификаторы** — без кавычек, если это валидный атом (`[a-z][A-Za-z0-9_]*`), иначе в `'...'`.
- **Тип узла** — атом (например, `person`, `org`).
- **Значения атрибутов** — всегда строки в `'...'`.

## 8. Частые проблемы

### «PyVis не установлен» / «PyAgentProlog не загружен»
```bash
pip install pyvis
```
Убедитесь, что пакет `prolog` находится в `sys.path`.

### «Встроенный text_to_prolog.py недоступен»
Файл повреждён или не может импортироваться. Проверьте консоль (там будет `SyntaxError` или `ImportError`).
Для работы NL-импорта также могут понадобиться: `pymorphy3`, `spacy`, `natasha`.

### «Не удалось прочитать PDF/DOCX»
Установите библиотеки:
```bash
pip install PyPDF2 python-docx
```

### «Нет решений» в запросе
Проверьте регистр: `apple` ≠ `Apple`. Строки `'2022'` и числа `2022` — разные вещи.

### Визуализация занимает мало места
Фон iframe и `#mynetwork` имеют `height:100%`. Если вы правили `graph_layout.py`, убедитесь, что CSS-блок `_PYVIS_INJECT` не повреждён.

## 10. Архитектура (для доработки)

| Файл | Роль |
|---|---|
| `app.py` | UI, handlers, тема, CLI, wiring |
| `graph_model.py` | `KnowledgeGraph` + CRUD + сериализация |
| `graph_layout.py` | `render_pyvis()` (основная) + `render_svg()` (backup) |
| `text_to_prolog.py` | NL → Prolog (опционально) |
| `assets/favicon.png` | Иконка приложения |

**Расширение:**
- **Типы и цвета** — `_NODE_TYPE_COLORS` (`app.py`) и `_TYPE_COLORS` (`graph_layout.py`).
- **Предикаты запросов** — `_CONVENIENCE_RULES` (`app.py`).
- **Тема PyVis** — `_PYVIS_OPTIONS` (`graph_layout.py`).
- **Размеры визуализации** — аргументы `render_pyvis(...)`.
