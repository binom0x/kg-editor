## 1. Установка и запуск

### 1.1. Требования

- Python 3.10+
- Пакет `prolog` (PyAgentProlog) в `sys.path`
- Пакет `pyvis` для интерактивной визуализации
- Пакет `gradio` 4.x / 5.x / 6.x

### 1.2. Установка зависимостей

```bash
pip install gradio pyvis
pip install pymorphy3 sentence-transformers  # опционально: NL-импорт
# PyAgentProlog: убедитесь, что каталог с пакетом `prolog/` в sys.path,
# либо установите его: pip install -e /путь/к/pyagentprolog
```

### 1.3. Запуск

```bash
python app.py
```

Откроется браузер на `http://127.0.0.1:7860`. Для доступа с других машин:

```bash
python -c "from app import launch; launch(host='0.0.0.0', port=7860)"
```

## 3. Работа с проектом (колонка 1)

### 3.1. 📂 Открыть

Загружает существующий `.pl` файл из файловой системы. Открывается диалог выбора файла — выберите `.pl`-файл с графом. Содержимое загружается в редактор, все таблицы обновляются.

### 3.2. 🆕 Создать

Создаёт новый проект в выбранной папке:

- открывается диалог выбора/создания папки
- в папке создаётся файл `graph.pl` с заголовком-комментарием
- файл сразу загружается в редактор

### 3.3. 💾 Сохранить

Сохраняет текущий граф в `.pl`-файл. Если файл уже открыт — перезаписывается он же; иначе открывается диалог «Сохранить как».

### 3.4. 📚 Демо-граф

Загружает демонстрационный граф: `apple`, `iphone`, `smartphone`, `elon_musk`, `spacex` с тремя рёбрами и двумя атрибутами. Удобно, чтобы быстро понять, как всё работает, не имея своего файла.

### 3.5. Статистика

Под кнопками — строка вроде:

> **Узлов:** 5 **Рёбер:** 3 **Атрибутов:** 2

Обновляется автоматически на каждое изменение.

### 3.6. 📝 Импорт из естественного языка

Вставьте текст и нажмите **✨ Извлечь в граф**:

```
Илон Маск владеет SpaceX. Apple выпустила iPhone 14 в 2022.
```

Извлекаются новые узлы, рёбра и атрибуты и **добавляются** к текущему графу (не заменяют). Работает русский и английский. Требует `text_to_prolog.py` и пакет `prolog` в `sys.path`.

### 3.7. 📥 Импорт из Prolog

Вставьте Prolog-факты и нажмите **📥 Разобрать**:

```prolog
node(apple, [], org).
edge(apple, iphone, releases).
attribute(iphone, release_year, '2022').
```

Текущий граф **заменяется** содержимым из текста. Понимает комментарии `%` и `/* */`, цитированные атомы `'...'`, числа, списки свойств `[key='value', ...]`.

### 3.8. 🔬 Диагностика

Показывает JSON с текущим состоянием:

```json
{
  "summary": {"nodes": 5, "edges": 3, "attributes": 2},
  "pyagentprolog": true,
  "text_to_prolog": true,
  "node_types": ["concept", "org", "person", "thing"],
  "predicates": ["owns", "produces", "releases"]
}
```

Полезно для проверки, что все зависимости подключены.

## 4. Редактор графа (колонка 2)

### 4.1. Вкладка «Узлы»

- Таблица **id / type / degree** с цветными чипами по типу.
- **Добавить:** введите `id` (`apple`) и `type` (`org`) → **➕**.
- **Удалить:** выберите из выпадающего списка → **🗑️**.
- Удаление узла автоматически удаляет все связанные рёбра и атрибуты.

**Палитра типов** (узел и его подпись в таблицах):

| Тип | Цвет |
|---|---|
| `concept` | 🔵 голубой |
| `person` | 🟢 зелёный |
| `org` / `organization` | 🟠 оранжевый |
| `place` / `loc` | 🟣 фиолетовый |
| `event` | 🔴 красный |
| `thing` | 💠 светло-голубой |
| `product` | 🟡 жёлто-оранжевый |

Произвольные типы получают серый по умолчанию, но это можно расширить — см. `_NODE_TYPE_COLORS` в `app.py`.

### 4.2. Вкладка «Рёбра»

- Таблица **idx / source / predicate / target**.
- **Добавить:** введите `source`, `target`, `predicate` → **➕**.
- Если узла `source` или `target` ещё нет — он создаётся автоматически с типом `concept`.
- **Удалить:** выберите из списка → **🗑️**.

### 4.3. Вкладка «Атрибуты»

- Таблица **idx / entity / name / value**.
- **Добавить:** введите `entity`, `name`, `value` → **➕**.
- Если `entity` ещё нет среди узлов — он создаётся.
- **Удалить:** выберите из списка → **🗑️**.

### 4.4. Вкладка «Prolog source»

Две части:

- **Сверху — цветной просмотр** с полноценной подсветкой:
  - зелёные курсивные `% комментарии`
  - голубые переменные `X`, `Id`
  - оранжевые строки `'...'`, `"..."`
  - фиолетовые числа `2022`
  - красные `:-`, `->`, `!`, `\+`, операторы

- **Ниже — аккордеон «✏️ Редактировать исходник»** — раскройте, чтобы править текст напрямую. Превью обновляется на лету.

Кнопки:

- **🔄 Обновить из графа** — пересобрать Prolog-текст из текущей модели графа.
- **📥 Применить из Prolog** — разобрать текст из аккордеона и **заменить** весь граф.

Это удобно для ручного редактирования большого графа или для копирования в другой проект.

## 5. Визуализация (колонка 3, верх)

Интерактивный PyVis-граф:

- **Узлы** — размер пропорционален степени, цвет — по типу.
- **Рёбра** — стрелки, предикат подписан посередине.
- **Hover** на узел — всплывает тултип `apple (org) — degree 2`.
- **Hover** на ребро — тултип `apple —[releases]→ iphone`.

**Управление:**

| Действие | Что делает |
|---|---|
| Колесо мыши | Зум вокруг курсора |
| Drag фона | Панорама |
| Кнопки `+` / `−` / `⟳` (справа сверху) | Зум / сброс |
| Стрелки `↑↓←→` | Панорама |
| Drag узла | Перетаскивание (физика пересчитает) |
| Hover на узле/ребре | Тултип с подробностями |

**Физика** (Barnes-Hut) стабилизируется за ~150 итераций; если граф «прыгает», подождите секунду — узлы разойдутся.

Граф **перерисовывается автоматически** на каждое изменение модели. Если граф большой (>100 узлов), перерисовка может занять 0.5–1 с.

## 6. Запросы (колонка 3, низ)

Движок — **PyAgentProlog** (`prolog.agent.Agent`). Каждый запрос выполняется на **свежем** агенте, мутации (`assertz`/`retract`) живут только в пределах одного запроса и не влияют на модель графа.

### 6.1. Синтаксис

Введите запрос в поле — точку в конце можно не ставить, добавится автоматически. Нажмите **▶ Запрос**.

### 6.2. Доступные предикаты

Поверх фактов автоматически добавляются правила:

```prolog
node(Id, Type) :- node(Id, _, Type).
edge(S, T) :- edge(S, T, _).
```

Поэтому в запросах доступны:

| Предикат | Пример |
|---|---|
| `node/2` | `node(apple, T).` |
| `node/3` | `node(Id, _, org).` |
| `edge/2` | `edge(S, T).` |
| `edge/3` | `edge(X, Y, owns).` |
| `attribute/3` | `attribute(iphone, release_year, Y).` |

Плюс стандартные: `\+`, `=`, `\=`, `==`, `>`, `<`, `is`, `findall/3`, `bagof/3`, `setof/3`, `member/2`, `append/3`, `length/2`, `atom/1`, `integer/1`, `compound/1`, `ground/1`.

### 6.3. Примеры запросов

**Все узлы с их типами:**
```prolog
node(Id, T).
```

**Все узлы типа `org`:**
```prolog
node(Id, org).
```

**Кто чем владеет:**
```prolog
edge(X, Y, owns).
```

**Все рёбра между разными узлами:**
```prolog
edge(A, B, _), \+ (A = B).
```

**Значение конкретного атрибута:**
```prolog
attribute(iphone, release_year, Y).
```

**Узлы, НЕ являющиеся персонами:**
```prolog
node(X, T), \+ (T = person).
```

**Все цели рёбер apple (через findall):**
```prolog
findall(X, edge(apple, X, _), L).
```

**Соседи двух шагов от apple:**
```prolog
edge(apple, X, _), edge(X, Y, _).
```

**Персона, владеющая org:**
```prolog
node(A, person), node(B, org), edge(A, B, owns).
```

### 6.4. Результат

Справа/снизу появляется JSON:

```json
[
  {"X": "elon_musk", "Y": "spacex"},
  {"X": "apple", "Y": "iphone"}
]
```

- Если в запросе нет переменных и он успешен — `{"result": true}`.
- Если решений нет — `Нет решений` в статусе.
- Лимит — 1000 решений (защита от бесконечных перечислений).

### 6.5. ℹ️ Помощь

Кнопка рядом с ▶ показывает список доступных предикатов и примеров.

## 7. Практический сценарий: от текста до запроса

1. **Открыть демо-граф** — 📚. В колонке 3 появится PyVis с 5 узлами.


## 8. Формат файла на диске

Сохранённый `.pl` — валидная Prolog-программа:

```prolog
node(apple, [], org).
node(iphone, [], thing).
node(spacex, [], org).
edge(apple, iphone, releases).
edge(elon_musk, spacex, owns).
attribute(iphone, release_year, '2022').
attribute(spacex, industry, 'aerospace').
```

- **Идентификаторы** — без кавычек, если это валидный атом (`[a-z][A-Za-z0-9_]*`), иначе в `'...'`. Это критично для запросов: `node(apple, X)` работает, а `node('apple', X)` уже не совпадёт.
- **Тип узла** — тоже атом.
- **Свойства** — список пар `[key='value', ...]` или `[]`.
- **Значения атрибутов** — всегда в `'...'` (это строки).

Такой файл можно грузить в PyAgentProlog напрямую (без редактора) — там будет работать тот же `node/3`, `edge/3`, `attribute/3`.

## 9. Частые проблемы

### «PyVis не установлен» / «PyAgentProlog не загружен»

```
pip install pyvis
```
И убедитесь, что каталог с `prolog/` в `sys.path`:
```python
import sys
sys.path.append('/путь/к/pyagentprolog')
```

### «text_to_prolog.py недоступен»

Положите `text_to_prolog.py` рядом с `app.py` или в `sys.path`. NL-импорт также требует `pymorphy3` (для RU) и `spacy + en_core_web_sm` (для EN).

### «Граф пуст» в визуализации

Нормально, если узлов нет. Добавьте узел или загрузите пример (📚).

### «Нет решений» в запросе

Проверьте регистр: атомы в Prolog чувствительны к регистру. `apple` ≠ `Apple`. `'2022'` (строка) ≠ `2022` (число).

### Визуализация занимает мало места по высоте

Фон iframe и `#mynetwork` должны быть `height:100%` — это уже учтено в `_PYVIS_INJECT`. Если вы правили `graph_layout.py` — проверьте, что `_PYVIS_INJECT` содержит `html,body{...height:100%}` и `.card{height:100%!important}`.

### «Gradio 6.0: theme/css/head must be passed to launch()»

Уже учтено — `app.py` автоматически определяет версию Gradio и передаёт параметры в правильное место.

## 11. Архитектура (для доработки)

| Файл | Роль |
|---|---|
| `app.py` | UI, handlers, тема, wiring |
| `graph_model.py` | `KnowledgeGraph` + CRUD + сериализация |
| `graph_layout.py` | `render_pyvis()` (основная) + `render_svg()` (backup) |
| `text_to_prolog.py` | NL → Prolog (опционально) |
| PyAgentProlog | движок запросов |

Расширение:

- **новые типы узлов и цвета** — `_NODE_TYPE_COLORS` в `app.py` и `_TYPE_COLORS` в `graph_layout.py`;
- **новые предикаты в запросах** — правки в `_CONVENIENCE_RULES` (`app.py`);
- **кастомная тема PyVis** — `_PYVIS_OPTIONS` в `graph_layout.py`;
- **другие размеры визуализации** — параметры `render_pyvis(..., height_ratio=..., max_height=..., min_height=...)`.
